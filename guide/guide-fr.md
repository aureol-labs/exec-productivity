# Votre assistant, en dix minutes

Trois gestes dans l'application Claude sur votre ordinateur. Un abonnement Claude Pro suffit.

## 1. Installer

Dans l'application Claude : **Plugins**, puis **Ajouter une marketplace** et coller
`paul-r-92/aureol-exec-productivity`. Installer **Aureol exec productivity**.

[capture : la carte du plugin, bouton Installer]

## 2. Lancer l'installation

Dans une nouvelle conversation, taper `/` puis choisir **aureol-exec-productivity:install**. Répondre aux
questions. Dix minutes. Ça se termine sur votre premier brief.

[capture : le menu / avec la commande install]

Pendant l'installation, l'assistant vous montre une carte pour chaque connexion qui manque. Cliquer, autoriser,
il vérifie ensuite lui-même.

| Connexion | Ce qu'elle apporte |
|---|---|
| Mails | la file de messages, les sujets en cours |
| Agenda | la journée, les réunions, les créneaux libres |
| Messagerie interne (Slack, Teams) | l'autre moitié de la file |
| Documents | les sources derrière chaque sujet |
| Réunions (Granola, Circleback, Fathom, tl;dv, Fireflies, Otter, Zoom) | les décisions, prises en réunion et écrites nulle part |

Si une connexion demande un administrateur, envoyez-lui le lien ; l'assistant continue sans elle.

[capture : une carte de connexion]

## 3. Épingler les trois pages

**Super Context**, **Brief du jour**, **Inbox prioritaire**. Chaque page arrive aussi par mail, avec son lien,
quand une habitude tourne.

[capture : les trois pages épinglées]

## Ce qui tourne tout seul

| Habitude | Quand |
|---|---|
| le brief | en semaine à 06:50, ou l'heure choisie |
| l'inbox | en semaine à 12:30 et 16:30 |
| la revue | le vendredi à 16:30 |

L'ordinateur peut être fermé : les habitudes tournent dans le cloud.

## Ce que l'assistant ne fait jamais

Envoyer, supprimer, déplacer, archiver, marquer comme lu. Il pose des étiquettes seulement si votre messagerie
le permet et selon des règles écrites dans vos mots, chacune listée sur la page.

## Une question, un problème

Taper `/aureol-exec-productivity:help` et dire ce que vous avez vu.
